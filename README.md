# jogos-mundodotrabalho
Plataforma de jogos sobre o Mundo do Trabalho e Educação Financeira.
Este repositório reúne materiais pedagógicos voltados para professores da EJA e do Ensino Fundamental (1º ao 5º ano), com foco nas transformações do mundo do trabalho.

🎯 Objetivo

Ajudar alunos a compreender 

Diferença entre trabalho formal e informal
Leis trabalhistas (CLT)
Profissões do passado e do presente
Profissões que podem desaparecer com o avanço das IAs
Como o trabalho funciona em outros países
